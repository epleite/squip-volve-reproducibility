# Data directory — licence boundary

**Important:** the root MIT licence applies to software, not automatically to data in this directory.

- `compact/` contains small reviewer-facing tables derived from the Equinor Volve release. Their use and redistribution remain subject to the current **Equinor Open Data Licence**.
- `results/` contains numerical outputs used in the manuscript. Outputs derived from Volve retain the corresponding attribution/use obligations.
- Raw Volve seismic volumes and original well files are not mirrored here.

See `../DATA_LICENSE.md` and `../docs/VOLVE_DATA.md` before reuse or redistribution.
